# 원본 내보내기 자료 — 보관 전용

문서 재구성 과정에서 원문 추적과 무결성 검증을 위해 보존한 파일이다. 활성 문서에서 사용하지 않는다.

## 포함 자료

- `source-overview.md`: 기존 전체 문서 인덱스
- `initial-documents.md`: 기존 초기 문서 인덱스
- `service-adr-aggregate.md`: ADR 분할 전 서비스 ADR 원본
- `erd-aggregate.md`: 데이터 문서 분할 전 ERD·DDL 원본
- `endpoints-all.csv`: 동일 레코드의 열 순서가 다른 중복 CSV
- `untitled.md`: 대응 API를 식별할 수 없는 내보내기 레코드

기존 인덱스의 링크는 내보내기 당시 경로를 기준으로 작성되었으므로 현재 탐색에 사용하지 않는다.
