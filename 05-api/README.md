# 05. API 명세

API 공통 규약, 실시간 이벤트, 엔드포인트 목록과 엔드포인트별 상세 명세를 관리한다.

## 현재 기준 문서

- [API 공통 규약 및 엔드포인트 요약](api-spec.md)
- [엔드포인트 상세 문서 인덱스](endpoints/README.md)
- [엔드포인트 카탈로그](catalog/endpoints.csv)

## 관리 기준

- 공통 인증, 오류, 페이지네이션과 WebSocket 이벤트는 `api-spec.md`에서 관리한다.
- 개별 요청·응답과 처리 조건은 `endpoints/`에서 관리한다.
- 엔드포인트 문서는 `도메인` 값을 기준으로 분류한다.  
- CSV는 API 목록과 개발 상태를 확인하기 위한 카탈로그이며 상세 동작의 기준 문서로 사용하지 않는다.
