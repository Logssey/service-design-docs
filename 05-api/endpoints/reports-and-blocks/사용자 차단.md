# 사용자 차단

도메인: REPORTS
Method: POST
URL: /api/v1/blocks
Version: 1
개발완료여부: Yes

**인증** `USER`

**Request** `BlockCreateRequest`

**Response** `BlockCreateResponse`

```java
// BlockCreateRequest
{
  "userId": 9   // @NotNull
}

// BlockCreateResponse (200)
{
  "blockId": 4,
  "blocked": true
}
```

멱등하게 동작한다. 이미 차단한 경우에도 200을 반환한다.

| 오류 | 상황 |
| --- | --- |
| 400 `INVALID_INPUT` | 본인 대상 |
| 404 `NOT_FOUND` | 존재하지 않는 사용자 |

관련: `FR-REPORT-004`
