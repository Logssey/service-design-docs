# 신고 접수

도메인: REPORTS
Method: POST
URL: /api/v1/reports
Version: 1
개발완료여부: No

#### 신고 사유 코드

```java
public enum ReportReasonCode {
    PROHIBITED_ITEM,      // 금지 품목
    FALSE_INFO,           // 허위 정보
    NO_SHOW,              // 약속 불이행
    SEXUAL_CONTENT,       // 음란성 내용
    FRAUD_SUSPICION,      // 사기 의심
    ABUSIVE_BEHAVIOR,     // 욕설·비방
    SPAM,                 // 광고·도배
    OTHER                 // 기타
}
```

대상 유형별 허용 코드는 서버에서 검증한다.

| 대상 | 허용 코드 |
| --- | --- |
| `LISTING` | `PROHIBITED_ITEM`, `FALSE_INFO`, `FRAUD_SUSPICION`, `SPAM`, `OTHER` |
| `USER` | `FRAUD_SUSPICION`, `ABUSIVE_BEHAVIOR`, `NO_SHOW`, `OTHER` |
| `MESSAGE` | `ABUSIVE_BEHAVIOR`, `SEXUAL_CONTENT`, `SPAM`, `OTHER` |
| `COMMUNITY_POST` | `FALSE_INFO`, `ABUSIVE_BEHAVIOR`, `SEXUAL_CONTENT`, `SPAM`, `OTHER` |
| `COMMUNITY_COMMENT` | `ABUSIVE_BEHAVIOR`, `SEXUAL_CONTENT`, `SPAM`, `OTHER` |

---

**인증** `USER`

**Request** `ReportCreateRequest`

**Response** `ReportCreateResponse`

```java
// ReportCreateRequest
{
  "targetType": "LISTING",              // @NotNull — LISTING | USER | MESSAGE | COMMUNITY_POST | COMMUNITY_COMMENT
  "targetId": 101,                      // @NotNull
  "reasonCode": "FRAUD_SUSPICION",      // @NotNull
  "detail": "허위 매물로 보입니다"        // @Size(max=500), 선택
}

// ReportCreateResponse (201)
{
  "reportId": 30,
  "status": "RECEIVED"
}
```

| 오류 | 상황 |
| --- | --- |
| 400 `INVALID_INPUT` | 본인 대상 신고, 대상 유형에 허용되지 않는 `reasonCode` |
| 403 `USER_SUSPENDED` | 이용정지 |
| 404 `NOT_FOUND` | 대상 리소스 없음 |
| 409 `CONFLICT` | 동일 대상·사유의 미처리 신고 존재 |

커뮤니티 대상도 동일한 신고 접수 API를 사용하며 별도 관리자 커뮤니티 화면을 만들지 않는다.

관련: `FR-REPORT-001`, `FR-REPORT-002`, `FR-COMM-010`
