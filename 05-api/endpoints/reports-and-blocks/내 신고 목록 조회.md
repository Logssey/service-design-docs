# 내 신고 목록 조회

도메인: REPORTS
Method: GET
URL: /api/v1/reports/me
Version: 1
개발완료여부: No

본인이 접수한 신고 목록.

**인증** `USER`

**Response** `CursorPageResponse<MyReportResponse>`

```java
// MyReportResponse
{
  "reportId": 30,
  "targetType": "LISTING",
  "targetId": 101,
  "reasonCode": "FRAUD_SUSPICION",
  "status": "RESOLVED",
  "resolution": "해당 게시글을 삭제 처리했습니다",
  "createdAt": "2026-03-15T10:00:00Z",
  "handledAt": "2026-03-15T14:00:00Z"
}
```

`resolution`은 처리 완료 전까지 `null`.

`targetType`은 `LISTING`, `USER`, `MESSAGE`, `COMMUNITY_POST`, `COMMUNITY_COMMENT` 중 하나다.

관련: `FR-REPORT-003`
