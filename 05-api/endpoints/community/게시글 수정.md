# 커뮤니티 게시글 수정

도메인: COMMUNITY
Method: PATCH
URL: /api/v1/community/posts/{postId}
Version: 1
개발완료여부: No

**인증** `USER` (`ACTIVE` 상태, 작성자)

**Request** `CommunityPostUpdateRequest`

**Response** `CommunityPostDetailResponse`

```java
// CommunityPostUpdateRequest — 모든 필드 선택, 하나 이상 필수
{
  "category": "TIP",             // GENERAL | QUESTION | TIP | SHARE
  "title": "중고 노트북 점검 팁",
  "content": "배터리 상태와 화면 불량부터 확인해 보세요"
}
```

전달한 필드만 변경한다. 제목은 2~100자, 본문은 10~3,000자로 검증하고 성공 시 `updatedAt`을 갱신한다.

| 오류 | 상황 |
| --- | --- |
| 400 `INVALID_INPUT` | 변경 필드 없음, 카테고리 또는 제목·본문 길이 위반 |
| 403 `FORBIDDEN` | 작성자 불일치 |
| 403 `USER_SUSPENDED` | `ACTIVE` 상태가 아닌 회원 |
| 404 `NOT_FOUND` | 게시글 없음, 삭제 또는 숨김 |

관련: `FR-COMM-004`
