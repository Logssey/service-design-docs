# 커뮤니티 댓글 삭제

도메인: COMMUNITY
Method: DELETE
URL: /api/v1/community/posts/{postId}/comments/{commentId}
Version: 1
개발완료여부: Yes

**인증** `USER` (`ACTIVE` 상태, 댓글 작성자)

**Response** 없음 (204)

댓글이 경로의 게시글에 속하는지 확인한 뒤 물리 삭제하지 않고 `deletedAt`과 `deletedBy`를 기록한다. 댓글 삭제와 게시글의 `commentCount` 감소는 한 트랜잭션으로 처리한다.

| 오류 | 상황 |
| --- | --- |
| 403 `FORBIDDEN` | 댓글 작성자 불일치 |
| 403 `USER_SUSPENDED` | `ACTIVE` 상태가 아닌 회원 |
| 404 `NOT_FOUND` | 게시글·댓글 없음 또는 이미 삭제 |

관련: `FR-COMM-007`
