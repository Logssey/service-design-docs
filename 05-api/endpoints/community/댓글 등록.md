# 커뮤니티 댓글 등록

도메인: COMMUNITY
Method: POST
URL: /api/v1/community/posts/{postId}/comments
Version: 1
개발완료여부: Yes

**인증** `USER` (`ACTIVE` 상태)

**Request** `CommunityCommentCreateRequest`

**Response** `CommunityCommentResponse`

```java
// CommunityCommentCreateRequest
{
  "content": "배터리 사이클과 액정 번인을 먼저 확인해 보세요." // @NotBlank @Size(min=1, max=500)
}

// CommunityCommentResponse (201)
{
  "commentId": 901,
  "author": { "userId": 7, "nickname": "고쳐쓰기" },
  "content": "배터리 사이클과 액정 번인을 먼저 확인해 보세요.",
  "isMine": true,
  "createdAt": "2026-09-22T07:00:00Z"
}
```

댓글 등록과 게시글의 `commentCount` 증가는 한 트랜잭션으로 처리한다. 이미지와 대댓글 식별자는 받지 않는다.

| 오류 | 상황 |
| --- | --- |
| 400 `INVALID_INPUT` | 빈 댓글 또는 500자 초과 |
| 403 `USER_SUSPENDED` | `ACTIVE` 상태가 아닌 회원 |
| 404 `NOT_FOUND` | 게시글 없음, 삭제 또는 숨김 |

관련: `FR-COMM-006`
