# 커뮤니티 게시글 삭제

도메인: COMMUNITY
Method: DELETE
URL: /api/v1/community/posts/{postId}
Version: 1
개발완료여부: Yes

**인증** `USER` (`ACTIVE` 상태, 작성자)

**Response** 없음 (204)

물리 삭제하지 않고 `deletedAt`과 `deletedBy`를 기록한다. 이후 게시글과 소속 댓글은 공개 조회에서 제외한다.

| 오류 | 상황 |
| --- | --- |
| 403 `FORBIDDEN` | 작성자 불일치 |
| 403 `USER_SUSPENDED` | `ACTIVE` 상태가 아닌 회원 |
| 404 `NOT_FOUND` | 게시글 없음 또는 이미 삭제 |

관련: `FR-COMM-004`
