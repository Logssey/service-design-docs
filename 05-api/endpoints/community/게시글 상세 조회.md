# 커뮤니티 게시글 상세 조회

도메인: COMMUNITY
Method: GET
URL: /api/v1/community/posts/{postId}
Version: 1
개발완료여부: No

**인증** — (선택적 Bearer 토큰: 로그인 시 `isMine` 계산)

**Response** `CommunityPostDetailResponse`

```java
// CommunityPostDetailResponse (200)
{
  "postId": 201,
  "category": "QUESTION",
  "author": {
    "userId": 5,           // 탈퇴 작성자는 null
    "nickname": "재사용러"
  },
  "title": "중고 노트북 점검 방법이 궁금해요",
  "content": "직거래 전에 어떤 항목을 확인하면 좋을까요?",
  "commentCount": 4,
  "viewCount": 36,
  "isMine": false,
  "createdAt": "2026-09-22T06:00:00Z",
  "updatedAt": "2026-09-22T07:10:00Z"
}
```

삭제되거나 신고 처리로 숨김 상태인 게시글은 `404 NOT_FOUND`로 응답한다. 탈퇴 작성자는 `author.userId=null`, `author.nickname="탈퇴한 사용자"`로 반환하며 `isMine=false`다. 비로그인 사용자의 `isMine`도 `false`다.

| 오류 | 상황 |
| --- | --- |
| 404 `NOT_FOUND` | 게시글 없음, 삭제 또는 숨김 |

관련: `FR-COMM-001`, `FR-COMM-009`
