# 커뮤니티 게시글 등록

도메인: COMMUNITY
Method: POST
URL: /api/v1/community/posts
Version: 1
개발완료여부: Yes

**인증** `USER` (`ACTIVE` 상태)

**Request** `CommunityPostCreateRequest`

**Response** `CommunityPostCreateResponse`

```java
// CommunityPostCreateRequest
{
  "category": "QUESTION",                 // @NotNull — GENERAL | QUESTION | TIP | SHARE
  "title": "중고 노트북 점검 방법이 궁금해요", // @NotBlank @Size(min=2, max=100)
  "content": "직거래 전에 확인할 항목을 알려주세요" // @NotBlank @Size(min=10, max=3000)
}

// CommunityPostCreateResponse (201)
{
  "postId": 201
}
```

이미지 첨부 필드는 제공하지 않는다.

| 오류 | 상황 |
| --- | --- |
| 400 `INVALID_INPUT` | 카테고리 또는 제목·본문 길이 위반 |
| 403 `USER_SUSPENDED` | `ACTIVE` 상태가 아닌 회원 |

관련: `FR-COMM-003`
