# 커뮤니티 게시글 목록 조회

도메인: COMMUNITY
Method: GET
URL: /api/v1/community/posts
Version: 1
개발완료여부: No

**인증** — (선택적 Bearer 토큰: 로그인 시 `isMine`과 차단 필터 적용)

**Request** `CommunityPostSearchRequest` (쿼리 파라미터)

**Response** `CursorPageResponse<CommunityPostSummaryResponse>`

```java
// CommunityPostSearchRequest
{
  "category": "QUESTION", // 선택 — GENERAL | QUESTION | TIP | SHARE
  "cursor": null,
  "size": 20               // @Max(100)
}

// CommunityPostSummaryResponse
{
  "postId": 201,
  "category": "QUESTION",
  "author": {
    "userId": 5,           // 탈퇴 작성자는 null
    "nickname": "재사용러"
  },
  "title": "중고 노트북 점검 방법이 궁금해요",
  "excerpt": "직거래 전에 어떤 항목을 확인하면 좋을까요?",
  "commentCount": 4,
  "viewCount": 35,
  "isMine": false,
  "createdAt": "2026-09-22T06:00:00Z",
  "updatedAt": "2026-09-22T07:10:00Z"
}
```

정렬은 `(createdAt, postId)` 내림차순으로 고정하며 커서는 이 두 값을 불투명하게 인코딩한다. `excerpt`는 본문의 표시용 요약이다.

삭제·숨김 게시글과 로그인 사용자가 차단한 작성자의 게시글은 제외한다. 탈퇴 작성자는 `author.userId=null`, `author.nickname="탈퇴한 사용자"`로 반환한다. 비로그인 또는 익명 작성자의 `isMine`은 `false`다.

관련: `FR-COMM-001`, `FR-COMM-002`, `FR-COMM-008`, `FR-COMM-009`
