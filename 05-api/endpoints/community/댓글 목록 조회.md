# 커뮤니티 댓글 목록 조회

도메인: COMMUNITY
Method: GET
URL: /api/v1/community/posts/{postId}/comments
Version: 1
개발완료여부: No

**인증** — (선택적 Bearer 토큰: 로그인 시 `isMine`과 차단 필터 적용)

**Request** `CursorPageRequest` (쿼리 파라미터)

**Response** `CursorPageResponse<CommunityCommentResponse>`

```java
// CommunityCommentResponse
{
  "commentId": 901,
  "author": {
    "userId": 7,           // 탈퇴 작성자는 null
    "nickname": "고쳐쓰기"
  },
  "content": "배터리 사이클과 액정 번인을 먼저 확인해 보세요.",
  "isMine": false,
  "createdAt": "2026-09-22T07:00:00Z"
}
```

정렬은 `(createdAt, commentId)` 내림차순으로 고정한다. 댓글은 대댓글 없는 평면 텍스트이며 삭제·숨김 댓글과 로그인 사용자가 차단한 작성자의 댓글은 제외한다.

탈퇴 작성자는 `author.userId=null`, `author.nickname="탈퇴한 사용자"`로 반환한다. 비로그인 또는 익명 작성자의 `isMine`은 `false`다.

| 오류 | 상황 |
| --- | --- |
| 404 `NOT_FOUND` | 게시글 없음, 삭제 또는 숨김 |

관련: `FR-COMM-005`, `FR-COMM-008`, `FR-COMM-009`
