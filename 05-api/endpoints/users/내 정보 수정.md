# 내 정보 수정

도메인: USERS
Method: PATCH
URL: /api/v1/users/me
Version: 1
개발완료여부: No

**인증** `USER`

**Request** `ProfileUpdateRequest`

**Response** `MyProfileResponse`

```java
// ProfileUpdateRequest — 모든 필드 선택
{
  "nickname": "재현2",    // @Size(min=2, max=20)
  "bio": "수정된 소개",    // @Size(max=200)
  "imageId": 42           // 검증 완료된 프로필 이미지
}
```

| 오류 | 상황 |
| --- | --- |
| 403 `FORBIDDEN` | 본인이 업로드하지 않은 이미지 |
| 403 `USER_SUSPENDED` | 이용정지 |
| 409 `CONFLICT` | 닉네임 중복 |

`imageId`를 생략하면 기존 이미지를 유지하고, 명시적 `null`은 기본 이미지로 되돌린다.
이미지는 본인 소유의 `VERIFIED`·`PROFILE`만 연결할 수 있다. 실제 응답 URL은 짧은 수명의 서명 URL이며 DB에는 내부 object key를 보관한다.
