# 닉네임 중복 확인

도메인: USERS
Method: GET
URL: /api/v1/users/nickname/check
Version: 1
개발완료여부: No

가입·프로필 수정 화면에서 닉네임 사용 가능 여부를 확인한다 (화면설계서 AUTH-002).

**인증** —

**Query Parameter**

| 이름 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| `nickname` | String | O | 2~20자 |

**Response** `NicknameAvailabilityResponse`

```java
// NicknameAvailabilityResponse (200)
{
  "available": true
}
```

닉네임은 프로필에 공개되는 값이므로 존재 여부를 노출해도 계정 열거 문제가 없다. **이메일에는 같은 확인 API를 두지 않는다** — 가입 여부가 드러나 `NFR-AUTH-018`과 충돌하므로, 이메일 중복은 가입 요청의 `409 CONFLICT`로만 알린다.

응답은 확인 시점의 결과이며 예약이 아니다. 가입 확정은 서버의 UNIQUE 제약이 판단한다.

| 오류 | 상황 |
| --- | --- |
| 400 `INVALID_INPUT` | 닉네임 형식·길이 위반 |

관련: `FR-AUTH-002`
