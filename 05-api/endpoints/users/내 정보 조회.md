# 내 정보 조회

도메인: USERS
Method: GET
URL: /api/v1/users/me
Version: 1
개발완료여부: Yes

**인증** `USER`

**Response** `MyProfileResponse`

```java
// MyProfileResponse (200)
{
  "userId": 1,
  "nickname": "재현",
  "profileImageUrl": "https://...",
  "bio": "안녕하세요",
  "role": "USER",
  "status": "ACTIVE",
  "suspendedUntil": null,
  "provider": "LOCAL",
  "emailVerified": false,
  "createdAt": "2026-01-10T03:00:00Z"
}
```

`provider`는 이 계정의 인증 수단(`KAKAO` / `LOCAL`)이다. 화면에서 비밀번호 변경 메뉴 노출 여부를 판단하는 데 쓴다.

`emailVerified`는 `LOCAL` 계정의 소유 확인 여부이며, 소셜 계정은 항상 `false`다. 미인증 상태를 화면에 표시하기 위한 값이다 (`FR-AUTH-014`).

> 두 필드는 본인 응답인 `MyProfileResponse`에만 둔다. 공용 `UserSummaryResponse`에 넣으면
> 다른 사용자의 인증 수단과 인증 상태까지 노출된다.
> 가입 직후 `AuthTokenResponse`에도 실을지는 프론트 화면 흐름 확인 후 결정한다.

관련: `FR-AUTH-005`, `FR-AUTH-014`
