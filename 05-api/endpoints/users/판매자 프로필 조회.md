# 판매자 프로필 조회

도메인: USERS
Method: GET
URL: /api/v1/users/{userId}/profile
Version: 1
개발완료여부: No

판매자 신뢰 정보.

**인증** —

**Response** `SellerProfileResponse`

```java
// SellerProfileResponse (200)
{
  "userId": 5,
  "nickname": "판매왕",
  "profileImageUrl": "https://...",
  "bio": "빠른 거래",
  "completedTradeCount": 23,
  "averageRating": 4.7,
  "reviewCount": 18,
  "joinedAt": "2025-11-02T00:00:00Z",
  "reportFlag": false
}
```

`reportFlag`는 최근 90일 내 `RESOLVED` 신고 3건 이상일 때 `true`다.

관련: `FR-TRUST-001`, `FR-TRUST-002`, `FR-TRUST-004`
