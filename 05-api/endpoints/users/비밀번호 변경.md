# 비밀번호 변경

도메인: USERS
Method: PATCH
URL: /api/v1/users/me/password
Version: 1
개발완료여부: No

로그인한 사용자가 현재 비밀번호를 확인한 뒤 새 비밀번호로 변경한다.

**인증** `USER`

**Request** `PasswordChangeRequest`

**Response** 없음 (204)

```java
// PasswordChangeRequest
{
  "currentPassword": "hunter22!",   // @NotBlank
  "newPassword": "hunter33!"        // @NotBlank @Size(min=8, max=128)
}
```

`LOCAL` 계정만 사용할 수 있다. 소셜 계정은 저장된 비밀번호가 없다.

성공하면 **해당 사용자에게 발급된 Refresh Token을 전부 폐기한다** (`NFR-AUTH-016`, ADR-005).

| 오류 | 상황 |
| --- | --- |
| 400 `INVALID_INPUT` | 소셜 계정, 새 비밀번호 길이 위반 |
| 401 `UNAUTHENTICATED` | 현재 비밀번호 불일치 |

> 소셜 계정의 변경 시도에 `400 INVALID_INPUT`을 주는 것은 규칙 명세를 따른 것이다.
> 입력 오류가 아니라 계정 종류상 불가능한 요청이므로 `409 CONFLICT`가 적절한지 재검토 중이다.

관련: `FR-AUTH-016`, `NFR-AUTH-015`, `NFR-AUTH-016`
