# 알림 목록 조회

도메인: NOTIFICATIONS
Method: GET
URL: /api/v1/notifications
Version: 1
개발완료여부: No

**인증** `USER`

**Request** `NotificationSearchRequest` (쿼리 파라미터)

**Response** `CursorPageResponse<NotificationResponse>`

```java
// NotificationSearchRequest
{
  "unreadOnly": false,   // 기본 false
  "cursor": null,
  "size": 20
}

// NotificationResponse
{
  "notificationId": 500,
  "type": "TRADE_ACCEPTED",
  "title": "거래 요청이 승인되었습니다",
  "body": "아이패드 프로 11인치",
  "targetType": "TRADE",
  "targetId": 55,
  "readAt": null,
  "createdAt": "2026-03-15T02:00:00Z"
}
```

**알림 유형**

| type | 발생 시점 |
| --- | --- |
| `TRADE_REQUESTED` | 거래 요청 수신 |
| `TRADE_ACCEPTED` | 거래 승인 |
| `TRADE_REJECTED` | 거래 거절 |
| `TRADE_COMPLETED` | 거래 완료 |
| `TRADE_CANCELED` | 거래 취소 |
| `CHAT_RECEIVED` | 새 메시지 |
| `REVIEW_RECEIVED` | 후기 등록 |
| `REPORT_RESOLVED` | 신고 처리 완료 |
| `NOTICE_PUBLISHED` | 공지사항 등록 |

관련: `FR-NOTI-002`
