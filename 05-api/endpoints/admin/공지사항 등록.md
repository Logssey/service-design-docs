# 공지사항 등록

도메인: ADMIN
Method: POST
URL: /api/v1/admin/notices
Version: 1
개발완료여부: Yes

**인증** `ADMIN`

아래 3개 엔드포인트를 함께 기술한다. 등록·수정·삭제 모두 `ADMIN` 역할이 필요하다 (`NFR-AUTH-007`).

| 메서드 | 경로 | Request | Response |
| --- | --- | --- | --- |
| POST | `/admin/notices` | `NoticeCreateRequest` | `NoticeCreateResponse` (201) |
| PATCH | `/admin/notices/{noticeId}` | `NoticeUpdateRequest` | `NoticeResponse` |
| DELETE | `/admin/notices/{noticeId}` | 없음 | 없음 (204) |

```java
// NoticeCreateRequest
{
  "title": "서비스 점검 안내",     // @NotBlank @Size(max=200)
  "content": "3월 20일 02:00...",  // @NotBlank @Size(max=5000)
  "isPinned": false
}

// NoticeUpdateRequest — 모든 필드 선택
{
  "title": "서비스 점검 안내 (변경)",
  "content": "...",
  "isPinned": true
}

// NoticeCreateResponse (201)
{
  "noticeId": 8
}
```

공지 등록 시 전체 사용자에게 `NOTICE_PUBLISHED` 알림을 발송한다.

관련: `FR-ADMIN-011`
