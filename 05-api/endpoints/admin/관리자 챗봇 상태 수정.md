# 관리자 챗봇 상태 수정

- 도메인: ADMIN
- Method: PATCH
- URL: /api/v1/admin/chatbot
- Version: 1
- 개발완료여부: Yes

현재 `ADMIN` 권한으로 추천 질문 챗봇의 운영 스위치를 바꾼다. DB 공유 설정이라 API 인스턴스 재시작 없이 반영되고, 상태가 달라질 때 감사 로그를 남긴다. 서버 환경 `CHATBOT_ENABLED=false`는 관리자가 해제할 수 없는 상위 차단 스위치다.

**Request**

```json
{"enabled": false}
```

**Response** `200`: [관리자 챗봇 상태 조회](<관리자 챗봇 상태 조회.md>)와 같은 상태 객체.

`enabled` 누락·null은 `400`, 인증 실패는 `401`, 관리자 권한이 아니면 `403`, 환경에서 차단한 상태로 켜려면 `409`, 설정 DB 오류는 `503`이다. 자유 입력은 이 스위치와 별개로 비활성 유지한다.

관련: `FR-AI-008`
