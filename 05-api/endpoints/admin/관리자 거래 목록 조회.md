# 관리자 거래 목록 조회

도메인: ADMIN
Method: GET
URL: /api/v1/admin/trades
Version: 1
개발완료여부: Yes

**인증** `ADMIN`

**Request** `AdminTradeSearchRequest` (쿼리 파라미터)

**Response** `CursorPageResponse<AdminTradeResponse>`

java

```java
// AdminTradeSearchRequest
{
  "status": "COMPLETED",   // 선택
  "userId": 5,             // 선택. 판매자 또는 구매자
  "cursor": null,
  "size": 20
}

// AdminTradeResponse
{
  "tradeId": 55,
  "status": "COMPLETED",
  "listing": { "listingId": 101, "title": "아이패드 프로 11인치", "price": 650000, "thumbnailUrl": null },
  "seller": { "userId": 5, "nickname": "판매왕", "profileImageUrl": null },
  "buyer": { "userId": 3, "nickname": "구매자A", "profileImageUrl": null },

```

중첩 DTO: `ListingBriefResponse`, `UserSummaryResponse`

수집하는 개인정보가 닉네임과 거래 이력뿐이며 신고 처리·분쟁 확인에 필요한 최소 범위이므로 추가 마스킹을 적용하지 않는다 (`NFR-DATA-011`).

관련: `FR-ADMIN-010`
