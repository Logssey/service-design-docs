# 신고 처리

도메인: ADMIN
Method: PATCH
URL: /api/v1/admin/reports/{reportId}
Version: 1
개발완료여부: No

신고 처리.

**인증** `ADMIN`

**Request** `ReportHandleRequest`

**Response** `ReportHandleResponse`

```java
// ReportHandleRequest
{
  "status": "RESOLVED",                      // @NotNull — IN_REVIEW | RESOLVED | REJECTED
  "resolution": "게시글을 삭제 처리했습니다",   // RESOLVED/REJECTED일 때 @NotBlank
  "action": "HIDE_LISTING"                   // 선택 — 아래 조치 코드 참고
}

// ReportHandleResponse (200)
{
  "reportId": 30,
  "status": "RESOLVED",
  "handledAt": "2026-03-15T14:00:00Z"
}
```

`action`을 지정하면 조치를 함께 수행한다. `SUSPEND_USER`는 기본 정지 기간(7일)을 적용한다.

| action | 대상 및 처리 |
| --- | --- |
| `HIDE_LISTING` | 중고거래 게시글 숨김 |
| `DELETE_LISTING` | 중고거래 게시글 삭제 |
| `HIDE_COMMUNITY_POST` | 커뮤니티 게시글 `status=HIDDEN` |
| `HIDE_COMMUNITY_COMMENT` | 커뮤니티 댓글 `status=HIDDEN`, 게시글 `commentCount` 감소 |
| `SUSPEND_USER` | 사용자 기본 7일 이용정지 |
| `NONE` | 콘텐츠·회원 상태 조치 없음 |

커뮤니티 조치는 대상과 일치하는 숨김 action만 허용하고, 이 기존 신고 처리 API에서 수행한다. 별도 관리자 커뮤니티 엔드포인트는 제공하지 않는다.

처리 완료 시 신고자에게 알림을 발송한다.

| 오류 | 상황 |
| --- | --- |
| 400 `INVALID_INPUT` | 처리 결과 누락 |
| 409 `CONFLICT` | 이미 최종 상태 |

관련: `FR-ADMIN-007`, `FR-ADMIN-008`, `FR-COMM-010`
