# 회원 상태 변경

도메인: ADMIN
Method: PATCH
URL: /api/v1/admin/users/{userId}/status
Version: 1
개발완료여부: No

회원 상태 변경. 사유 필수.

**인증** `ADMIN`

**Request** `UserStatusUpdateRequest`

**Response** `UserStatusUpdateResponse`

```java
// UserStatusUpdateRequest
{
  "status": "SUSPENDED",                       // @NotNull — ACTIVE | SUSPENDED
  "suspendedUntil": "2026-03-22T00:00:00Z",    // SUSPENDED일 때. null이면 무기한
  "reason": "반복적인 허위 매물 등록"            // @NotBlank @Size(max=500)
}

// UserStatusUpdateResponse (200)
{
  "userId": 9,
  "status": "SUSPENDED",
  "suspendedUntil": "2026-03-22T00:00:00Z"
}
```

`SUSPENDED`로 전환 시 해당 사용자의 Refresh Token을 전부 폐기한다.

| 오류 | 상황 |
| --- | --- |
| 400 `INVALID_INPUT` | 사유 누락 |
| 403 `FORBIDDEN` | 본인 대상 |

관련: `FR-ADMIN-004`, `FR-ADMIN-005`
