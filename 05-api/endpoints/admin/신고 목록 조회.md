# 신고 목록 조회

도메인: ADMIN
Method: GET
URL: /api/v1/admin/reports
Version: 1
개발완료여부: No

**인증** `ADMIN`

**Request** `AdminReportSearchRequest` (쿼리 파라미터)

**Response** `CursorPageResponse<AdminReportResponse>`

```java
// AdminReportSearchRequest
{
  "status": "RECEIVED",      // 선택
  "targetType": "LISTING",   // 선택
  "cursor": null,
  "size": 20
}

// AdminReportResponse
{
  "reportId": 30,
  "reporter": {
    "userId": 3,
    "nickname": "구매자A",
    "profileImageUrl": null
  },
  "targetType": "LISTING",
  "targetId": 101,
  "targetSummary": "아이패드 프로 11인치",
  "reasonCode": "FRAUD_SUSPICION",
  "detail": "허위 매물로 보입니다",
  "status": "RECEIVED",
  "handledBy": null,
  "resolution": null,
  "createdAt": "2026-03-15T10:00:00Z"
}
```

중첩 DTO: `UserSummaryResponse`

`targetType` 필터는 `LISTING`, `USER`, `MESSAGE`, `COMMUNITY_POST`, `COMMUNITY_COMMENT`를 허용한다.

`targetSummary`는 대상 유형에 따라 중고거래·커뮤니티 게시글 제목, 닉네임, 메시지·커뮤니티 댓글 내용 일부를 반환한다. 커뮤니티 콘텐츠도 이 기존 신고 목록에서만 관리한다.

관련: `FR-ADMIN-006`, `FR-COMM-010`
