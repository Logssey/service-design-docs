# 회원 목록 조회

도메인: ADMIN
Method: GET
URL: /api/v1/admin/users
Version: 1
개발완료여부: No

**인증** `ADMIN`

**Request** `AdminUserSearchRequest` (쿼리 파라미터)

**Response** `CursorPageResponse<AdminUserResponse>`

```java
// AdminUserSearchRequest
{
  "status": "ACTIVE",    // 선택
  "keyword": "재현",      // 닉네임 검색, 선택
  "cursor": null,
  "size": 20
}

// AdminUserResponse
{
  "userId": 1,
  "nickname": "재현",
  "role": "USER",
  "status": "ACTIVE",
  "suspendedUntil": null,
  "listingCount": 5,
  "reportedCount": 0,
  "createdAt": "2026-01-10T03:00:00Z"
}
```

`reportedCount`는 해당 사용자를 대상으로 접수된 신고의 **전체 건수**다. 판매자 프로필의 `reportFlag`와 기준이 다르다.

관련: `FR-ADMIN-003`
