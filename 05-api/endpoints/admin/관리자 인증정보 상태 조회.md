# 관리자 인증정보 상태 조회

- 도메인: ADMIN
- Method: GET
- URL: /api/v1/admin/credentials/status
- Version: 1
- 개발완료여부: Yes

현재 `ADMIN` 권한으로 서비스 연동 설정의 **존재와 사용 여부만** 조회한다. 현재 DB의 역할을 서버에서 다시 검증한다. 실제 연결 성공·자격증명 유효성이나 교체 시각을 보장하는 엔드포인트가 아니다.

**Response** `200`

```json
{
  "credentials": [
    {"service": "JWT", "configured": true, "enabled": true, "source": "APPLICATION_CONFIGURATION"},
    {"service": "IMAGE_STORAGE", "configured": true, "enabled": true, "source": "DEFAULT_PROVIDER_CHAIN"}
  ]
}
```

`service`는 `JWT`, `DATABASE`, `REDIS`, `SMTP`, `KAKAO_OAUTH`, `IMAGE_STORAGE`, `LLM` 중 하나다. `source`는 `APPLICATION_CONFIGURATION`(실제 시크릿 저장 출처를 단정하지 않음) 또는 `DEFAULT_PROVIDER_CHAIN`이다. 로컬 카카오 대역에서는 `KAKAO_OAUTH`가 미설정·비활성으로 표시된다. 비밀번호·토큰·키의 값/일부/지문, 환경 변수명, URL, 사용자명은 응답과 로그에 포함하지 않는다. 조회 행위는 관리자 ID만 감사 기록에 남긴다. 인증 실패는 `401`, 관리자 권한이 아니면 `403`이다.

비밀값 교체는 관리자 UI에서 직접 하지 않는다. 승인된 운영 권한으로 비밀 저장소를 갱신하고 서비스 재배포·재시작 및 동작 검증을 수행한다. 운영 권한 정책과 교체 시험을 완료하기 전에는 `FR-CRED-004/006`을 완전히 검증했다고 보지 않는다.

관련: `FR-CRED-004~006`, `NFR-CRED-001~007`
