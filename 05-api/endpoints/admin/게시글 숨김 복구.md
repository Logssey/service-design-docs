개발완료여부: No

게시글 숨김·복구. 사유 필수.

**인증** `ADMIN`

**Request** `AdminListingStatusRequest`

**Response** `AdminListingStatusResponse`

```java
// AdminListingStatusRequest
{
  "status": "HIDDEN",                  // @NotNull — HIDDEN | RESTORE
  "reason": "허위 매물로 확인됨"         // @NotBlank @Size(max=500)
}

// AdminListingStatusResponse (200)
{
  "listingId": 101,
  "status": "HIDDEN"
}
```

`RESTORE`는 숨김 직전 상태로 되돌린다.
