# 게시글 숨김/복구

도메인: ADMIN
Method: PATCH
URL: /api/v1/admin/listings/{listingId}/status
Version: 1
개발완료여부: Yes

게시글 숨김·복구. 사유 필수.

**인증** `ADMIN`

**Request** `AdminListingStatusRequest`

**Response** `AdminListingStatusResponse`

```java
// AdminListingStatusRequest
{
  "status": "HIDDEN",                  // @NotNull — HIDDEN | RESTORE
  "reason": "허위 매물로 확인됨"         // @NotBlank @Size(max=500)
}

// AdminListingStatusResponse (200)
{
  "listingId": 101,
  "status": "HIDDEN"
}
```

`RESTORE`는 감사 기록의 숨김 이전 상태와 현재 거래 상태를 함께 확인한다. 숨김 중에도 기존 ACCEPTED 거래는 완료·취소할 수 있으며 게시글은 계속 HIDDEN으로 유지한다. 복구 시 완료된 거래가 있으면 COMPLETED, 승인 거래가 남으면 RESERVED, 승인 거래가 취소되었으면 ON_SALE로 복구한다. 상태 근거가 없으면 409를 반환한다.

소유자는 숨김 상태에서 내용을 수정할 수 있지만 공개 조회는 계속 404이고, 관리자 복구 전에는 노출되지 않는다.

관련: `FR-ADMIN-007`
