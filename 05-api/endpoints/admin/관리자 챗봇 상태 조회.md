# 관리자 챗봇 상태 조회

- 도메인: ADMIN
- Method: GET
- URL: /api/v1/admin/chatbot
- Version: 1
- 개발완료여부: Yes

현재 `ADMIN` 권한으로 챗봇 운영 상태를 조회한다. 실제 사용 가능 여부는 서버 환경의 `CHATBOT_ENABLED`와 관리자가 DB에 저장한 설정을 모두 반영한다.

**Response** `200`

```json
{
  "enabled": true,
  "adminEnabled": true,
  "environmentEnabled": true,
  "freeInputEnabled": false
}
```

`freeInputEnabled`는 별도 `CHATBOT_FREE_INPUT_ENABLED`도 켜진 경우에만 참이다. 운영 기본 정책은 자유 입력 비활성이다. 인증 실패는 `401`, 관리자 권한이 아니면 `403`, 설정 DB를 읽을 수 없으면 `503`이다.

관련: `FR-AI-008`
