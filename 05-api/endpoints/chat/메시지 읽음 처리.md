# 메시지 읽음 처리

도메인: CHAT
Method: POST
URL: /api/v1/chat-rooms/{chatRoomId}/read
Version: 1
개발완료여부: No

읽음 처리.

**인증** `USER` (참여자)

**Request** `MessageReadRequest`

**Response** `MessageReadResponse`

```java
// MessageReadRequest
{
  "lastReadMessageId": 987   // @NotNull
}

// MessageReadResponse (200)
{
  "chatRoomId": 12,
  "unreadCount": 0
}
```

해당 메시지 이하의 상대방 발신 메시지에 `read_at`을 기록한다.

관련: `FR-CHAT-004`
