# 메시지 목록 조회

도메인: CHAT
Method: GET
URL: /api/v1/chat-rooms/{chatRoomId}/messages
Version: 1
개발완료여부: Yes

**인증** `USER` (참여자)

**Request** `CursorPageRequest`

**Response** `CursorPageResponse<MessageResponse>`

```java
// MessageResponse
{
  "messageId": 987,
  "senderId": 5,
  "content": "네 그 시간에 뵐게요",
  "isMine": false,
  "isDeleted": false,
  "readAt": "2026-03-15T08:21:00Z",
  "createdAt": "2026-03-15T08:20:00Z"
}
```

`message_id` 내림차순(최신순). `isDeleted`가 `true`면 `content`는 `null`이다.

| 오류 | 상황 |
| --- | --- |
| 403 `FORBIDDEN` | 참여자 아님 |

관련: `FR-CHAT-006`
