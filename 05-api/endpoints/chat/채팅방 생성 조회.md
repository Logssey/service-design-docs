# 채팅방 생성/조회

도메인: CHAT
Method: POST
URL: /api/v1/chat-rooms
Version: 1
개발완료여부: No

채팅방 생성 또는 기존 방 반환.

**인증** `USER`

**Request** `ChatRoomCreateRequest`

**Response** `ChatRoomCreateResponse`

```java
// ChatRoomCreateRequest
{
  "listingId": 101   // @NotNull
}

// ChatRoomCreateResponse (200)
{
  "chatRoomId": 12,
  "created": false
}
```

`created`가 `false`면 기존 방을 반환한 것이다. 동일 게시글·구매자 조합은 방 하나만 존재한다.

| 오류 | 상황 |
| --- | --- |
| 400 `INVALID_INPUT` | 본인 게시글 |
| 403 `FORBIDDEN` | 차단 관계 존재 |
| 403 `USER_SUSPENDED` | 이용정지 |
| 404 `NOT_FOUND` | 삭제된 게시글 |

관련: `FR-CHAT-001`
