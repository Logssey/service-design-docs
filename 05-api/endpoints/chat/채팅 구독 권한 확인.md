# 채팅 구독 권한 확인

도메인: CHAT
Method: GET
URL: /api/v1/chat-rooms/{chatRoomId}/subscription
Version: 1
개발완료여부: Yes

**인증** `USER` (참여자)

Socket.IO 구독과 실시간 이벤트 전달 직전에 현재 계정·참여자·양방향 차단 상태를 확인한다.

**Response** `{"userId": 5, "chatRoomId": 12}` (200)

없는 방은 404, 참여자가 아니거나 차단 관계가 있으면 403, 잘못된 토큰·탈퇴 계정은 401이다. 메시지 내용은 이 API에서 반환하지 않는다.
