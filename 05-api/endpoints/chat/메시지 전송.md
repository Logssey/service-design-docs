# 메시지 전송

도메인: CHAT
Method: POST
URL: /api/v1/chat-rooms/{chatRoomId}/messages
Version: 1
개발완료여부: No

메시지 전송. 저장 후 채팅 서버가 Redis Pub/Sub으로 상대방에게 전달한다.

**인증** `USER` (참여자)

**Request** `MessageSendRequest`

**Response** `MessageResponse` (201)

```java
// MessageSendRequest
{
  "content": "안녕하세요, 직거래 가능할까요?"   // @NotBlank @Size(max=1000)
}
```

| 오류 | 상황 |
| --- | --- |
| 403 `FORBIDDEN` | 참여자 아님, 차단 관계 존재 |
| 403 `USER_SUSPENDED` | 이용정지 |

실시간 전달에 실패해도 저장된 메시지는 조회로 복구 가능하다.

관련: `FR-CHAT-002`
