# 후기 작성

도메인: REVIEWS
Method: POST
URL: /api/v1/reviews
Version: 1
개발완료여부: Yes

#### POST `/reviews`

**인증** `USER` (거래 당사자)

**Request** `ReviewCreateRequest`

**Response** `ReviewCreateResponse`

```java
// ReviewCreateRequest
{
  "tradeId": 55,                  // @NotNull
  "rating": 5,                    // @NotNull @Min(1) @Max(5)
  "content": "친절했습니다"        // @Size(max=500), 선택
}

// ReviewCreateResponse (201)
{
  "reviewId": 10
}
```

| 오류 | 상황 |
| --- | --- |
| 403 `FORBIDDEN` | 거래 당사자 아님 |
| 403 `USER_SUSPENDED` | 이용정지 |
| 409 `CONFLICT` | 거래가 `COMPLETED` 아님, 이미 작성함 |

`reviewee_id`는 서버가 거래 정보에서 판단한다. 클라이언트가 지정할 수 없다.

관련: `FR-REVIEW-001~004`
