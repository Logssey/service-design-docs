# 챗봇 메시지 전송

도메인: CHATBOT
Method: POST
URL: /api/v1/chatbot/messages
Version: 1
개발완료여부: No

질문 전송. 추천 질문 선택 시 사전 정의된 답변을 반환하고, 자유 입력 시 외부 LLM API를 호출한다 (ADR-003).

**현재 제한:** `questionId` 경로는 동작하지만 사용자 결정에 따라 `message` 자유 입력은 비활성 유지한다. [백엔드 #44](https://github.com/Logssey/service-backend/issues/44)가 병합되면 `CHATBOT_FREE_INPUT_ENABLED=false`가 기본값이며, LLM API 키가 있어도 자유 입력은 외부 전송 없이 503을 반환한다. 이 때문에 본 엔드포인트 전체를 완료로 표시하지 않는다. 자유 입력을 재개하려면 개인정보 전송 정책과 `NFR-EXT-004` 검증이 먼저 필요하다.

**인증** `USER`

**Request** `ChatbotMessageRequest`

**Response** `ChatbotMessageResponse`

```java
// ChatbotMessageRequest
{
  "questionId": 1,      // 추천 질문 선택 시
  "message": null       // 자유 입력 시. @Size(max=500)
}
```

`questionId`와 `message` 중 하나만 지정한다.

```java
// ChatbotMessageResponse (200)
{
  "answer": "구매자가 거래를 요청하면 판매자가 승인하고, 직거래 후 구매자가 완료를 확정합니다.",
  "source": "PREDEFINED"
}

// ChatbotMessageResponse — 범위 외 질문 (200)
{
  "answer": "서비스 이용과 관련된 질문에만 답변할 수 있습니다.",
  "source": "OUT_OF_SCOPE"
}
```

`source`는 `PREDEFINED` / `LLM` / `OUT_OF_SCOPE`.

| 오류 | 상황 |
| --- | --- |
| 400 `INVALID_INPUT` | 두 필드 모두 지정 또는 모두 누락 |
| 429 `RATE_LIMITED` | 분당 5회 초과 |
| 502 `EXTERNAL_SERVICE_ERROR` | LLM API 실패·타임아웃 |
| 503 `SERVICE_UNAVAILABLE` | 챗봇 전체 비활성화, 자유 입력 비활성화 또는 LLM 미설정 |

LLM 요청에 사용자 개인정보를 포함하지 **않아야 한다** (`NFR-EXT-004`). 기존 마스킹만으로 이름·주소 등을 모두 제거한다고 보장할 수 없어 자유 입력을 비활성화한다. 추천 질문 ID 선택은 사전 정의 답변만 반환하며 LLM을 호출하지 않는다.

관련: `FR-AI-002~007`
