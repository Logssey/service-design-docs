# 이미지 업로드 완료

도메인: IMAGES
Method: POST
URL: /api/v1/images/{imageId}/complete
Version: 1
개발완료여부: Yes

업로드 완료 통보. 서버가 실제 객체를 재검증한다.

**인증** `USER` (업로더)

**Request** 없음

**Response** `ImageUploadResultResponse`

```java
// ImageUploadResultResponse (200)
{
  "imageId": 7,
  "status": "VERIFIED",
  "url": "https://...",
  "thumbnailUrl": "https://..."
}
```

`thumbnailUrl`은 1차 릴리스에서 원본 URL과 동일한 값을 반환한다 (후반부 18절 참조).

| 오류 | 상황 |
| --- | --- |
| 400 `INVALID_INPUT` | 검증 실패. `status`가 `REJECTED`로 전환 |
| 403 `FORBIDDEN` | `uploader_id` 불일치 |

클라이언트가 전달한 `contentType`을 신뢰하지 않고 실제 파일을 재검증한다.

관련: `FR-IMG-002`, `NFR-DATA-008`
