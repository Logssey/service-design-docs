# 게시글 등록

도메인: LISTINGS
Method: POST
URL: /api/v1/listings
Version: 1
개발완료여부: Yes

**인증** `USER`

**Request** `ListingCreateRequest`

**Response** `ListingCreateResponse`

```java
// ListingCreateRequest
{
  "title": "아이패드 프로 11인치",   // @NotBlank @Size(min=2, max=100)
  "description": "2년 사용했습니다", // @NotBlank @Size(max=2000)
  "price": 650000,                   // @NotNull @Min(0) @Max(100000000)
  "itemCondition": "LIKE_NEW",       // @NotNull
  "tradeMethod": "BOTH",             // @NotNull
  "categoryId": 1,                   // @NotNull
  "imageIds": [7, 8, 9]              // @Size(max=5)
}

// ListingCreateResponse (201)
{
  "listingId": 101
}
```

| 오류 | 상황 |
| --- | --- |
| 400 `INVALID_INPUT` | 필드 검증 실패, 이미지 6장 이상 |
| 403 `FORBIDDEN` | 본인이 업로드하지 않은 이미지 |
| 403 `USER_SUSPENDED` | 이용정지 |
| 409 `CONFLICT` | 이미 다른 게시글에 연결된 이미지 |

관련: `FR-LIST-001~003`
