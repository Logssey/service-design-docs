# 게시글 수정

도메인: LISTINGS
Method: PATCH
URL: /api/v1/listings/{listingId}
Version: 1
개발완료여부: No

**인증** `USER` (소유자)

**Request** `ListingUpdateRequest`

**Response** `ListingDetailResponse`

```java
// ListingUpdateRequest — 모든 필드 선택
{
  "title": "아이패드 프로 11인치 (가격 인하)",
  "description": "...",
  "price": 600000,
  "itemCondition": "LIKE_NEW",
  "tradeMethod": "DIRECT",
  "categoryId": 1,
  "imageIds": [7, 8]
}
```

| 오류 | 상황 |
| --- | --- |
| 403 `FORBIDDEN` | `seller_id` 불일치 |
| 403 `USER_SUSPENDED` | 이용정지 |
| 404 `NOT_FOUND` | 삭제된 게시글 |

관련: `FR-LIST-004`
