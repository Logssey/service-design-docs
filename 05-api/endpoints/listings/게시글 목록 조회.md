# 게시글 목록 조회

도메인: LISTINGS
Method: GET
URL: /api/v1/listings
Version: 1
개발완료여부: Yes

**인증** — (로그인 시 차단 필터 적용)

**Request** `ListingSearchRequest` (쿼리 파라미터)

**Response** `CursorPageResponse<ListingSummaryResponse>`

```java
// ListingSearchRequest
{
  "keyword": "아이패드",      // @Size(max=50)
  "categoryId": 1,
  "status": "ON_SALE",
  "minPrice": 100000,
  "maxPrice": 1000000,
  "sort": "latest",          // latest | priceAsc | priceDesc
  "cursor": null,
  "size": 20                 // @Max(100)
}

// ListingSummaryResponse
{
  "listingId": 101,
  "title": "아이패드 프로 11인치",
  "price": 650000,
  "status": "ON_SALE",
  "itemCondition": "LIKE_NEW",
  "thumbnailUrl": "https://...",
  "wishCount": 12,
  "seller": {
    "userId": 5,
    "nickname": "판매왕",
    "profileImageUrl": "https://..."
  },
  "createdAt": "2026-03-14T08:00:00Z"
}
```

`seller`는 `UserSummaryResponse`. `thumbnailUrl`은 첫 번째 이미지의 URL이다.

삭제·숨김 게시글과 차단한 사용자의 게시글은 제외한다.

관련: `FR-LIST-006`, `FR-LIST-008`, `FR-LIST-009`, `FR-REPORT-005`
