# 이메일 로그인

도메인: AUTH
Method: POST
URL: /api/v1/auth/email/login
Version: 1
개발완료여부: No

이메일·비밀번호로 로그인.

**인증** —

**Request** `EmailLoginRequest`

**Response** `AuthTokenResponse`

```java
// EmailLoginRequest
{
  "email": "user@example.com",   // @NotBlank @Email
  "password": "hunter22!"         // @NotBlank
}

// AuthTokenResponse (200)
{
  "accessToken": "eyJhbGci...",
  "user": {
    "userId": 11,
    "nickname": "재현",
    "profileImageUrl": null
  }
}
```

Refresh Token은 바디가 아닌 HttpOnly 쿠키로 설정한다.

**이메일 미존재와 비밀번호 불일치를 같은 코드와 같은 메시지로 응답한다.** 계정 존재 여부가 오류 응답으로 드러나서는 안 된다 (`NFR-AUTH-018`). 응답 시간 차이로도 추론되지 않도록 처리한다.

반복 실패는 동일 계정 기준 10분당 5회로 제한하며, 계정 잠금이 아닌 요청 지연·차단으로 처리한다 (`NFR-AUTH-019`).

| 오류 | 상황 |
| --- | --- |
| 401 `UNAUTHENTICATED` | 이메일 미존재 또는 비밀번호 불일치 |
| 403 `USER_SUSPENDED` | 이용정지 계정 |
| 429 `RATE_LIMITED` | 로그인 시도 제한 초과 |

관련: `FR-AUTH-013`, `NFR-AUTH-018`, `NFR-AUTH-019`
