# 비밀번호 재설정 요청

도메인: AUTH
Method: POST
URL: /api/v1/auth/password/reset
Version: 1
개발완료여부: Yes

비밀번호를 잊은 사용자에게 재설정 코드를 발송한다.

**인증** —

**Request** `PasswordResetRequest`

**Response** 없음 (204)

```java
// PasswordResetRequest
{
  "email": "user@example.com"   // @NotBlank @Email
}
```

**계정 유무와 무관하게 항상 204로 응답한다.** 가입되지 않은 주소, 소셜 계정의 주소, 탈퇴한 계정의 주소 모두 같은 응답을 준다. 코드는 실제로 존재하는 `LOCAL` 계정에만 발송한다 (`NFR-AUTH-018`).

코드는 Redis에 저장하며 유효기간 10분, 1회 사용이다 (ADR-010, `NFR-AUTH-017`).

| 오류 | 상황 |
| --- | --- |
| 400 `INVALID_INPUT` | 이메일 형식 위반 |
| 429 `RATE_LIMITED` | 발송 간격·횟수 제한 초과 |

관련: `FR-AUTH-015`, `NFR-AUTH-017`, `NFR-AUTH-018`
