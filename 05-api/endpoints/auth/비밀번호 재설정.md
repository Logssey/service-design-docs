# 비밀번호 재설정

도메인: AUTH
Method: POST
URL: /api/v1/auth/password/reset/confirm
Version: 1
개발완료여부: Yes

발송된 코드로 비밀번호를 재설정한다.

**인증** —

**Request** `PasswordResetConfirmRequest`

**Response** 없음 (204)

```java
// PasswordResetConfirmRequest
{
  "email": "user@example.com",   // @NotBlank @Email
  "code": "483920",               // @NotBlank
  "newPassword": "hunter33!"      // @NotBlank @Size(min=8, max=128)
}
```

성공하면 **해당 사용자에게 발급된 Refresh Token을 전부 폐기한다** (`NFR-AUTH-016`, ADR-005). 다른 기기의 세션이 함께 끊긴다.

만료·재사용·불일치를 구분하지 않고 같은 코드로 응답한다. 코드당 검증 시도는 5회로 제한한다 (`NFR-AUTH-017`).

재설정 코드는 `LOCAL` 계정에만 발급되므로, 소셜 계정에만 등록된 이메일로 요청하면 항상 `400 INVALID_INPUT`이다. 같은 주소의 `LOCAL` 계정이 있으면 그 `LOCAL` 계정의 비밀번호만 바뀐다 (ADR-019).

| 오류 | 상황 |
| --- | --- |
| 400 `INVALID_INPUT` | 코드 만료·재사용·불일치, 비밀번호 길이 위반 |
| 429 `RATE_LIMITED` | 검증 시도 제한 초과 |

관련: `FR-AUTH-015`, `NFR-AUTH-015~018`
