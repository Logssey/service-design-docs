# 이메일 소유 확인 코드 발송

도메인: AUTH
Method: POST
URL: /api/v1/auth/email/verification
Version: 1
개발완료여부: Yes

로그인한 사용자의 인증 수단에 등록된 이메일로 소유 확인 코드를 재발송한다. 이메일 가입과, 이메일을 입력한 소셜 온보딩에서는 서버가 가입 직후 1회 자동 발송하므로 이 엔드포인트는 재발송 용도다.

**인증** `USER`

**Request** 없음

**Response** 없음 (204)

대상 주소는 토큰의 사용자에 연결된 인증 수단의 이메일이다(`LOCAL`은 가입 이메일, 소셜은 온보딩에서 입력한 이메일, ADR-019). 요청 바디로 주소를 받지 않는다 — 임의 주소로 메일을 보낼 수 있는 경로를 만들지 않기 위해서다.

코드는 Redis에 저장하며 유효기간 10분, 1회 사용이다 (ADR-010, `NFR-AUTH-017`). 재발송은 60초 간격, 시간당 5회로 제한한다.

같은 주소가 다른 소셜 계정에서 이미 소유 확인되어 있어도 재발송은 막지 않는다. 그 판정은 코드로 소유를 증명한 뒤 [이메일 소유 확인](<이메일 소유 확인.md>)에서 한다. 발송 단계에서 거절하면 소유 증명 없이 그 주소의 가입 여부가 드러난다 (`NFR-AUTH-018`).

| 오류 | 상황 |
| --- | --- |
| 409 `CONFLICT` | 인증 수단에 등록된 이메일이 없음(온보딩에서 이메일을 입력하지 않은 소셜 계정), 또는 이미 소유 확인이 완료된 이메일 |
| 429 `RATE_LIMITED` | 재발송 간격·횟수 제한 초과 |

관련: `FR-AUTH-014`, `FR-AUTH-017`, `NFR-AUTH-017`
