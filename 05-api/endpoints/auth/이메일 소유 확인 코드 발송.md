# 이메일 소유 확인 코드 발송

도메인: AUTH
Method: POST
URL: /api/v1/auth/email/verification
Version: 1
개발완료여부: Yes

로그인한 이메일 계정의 소유 확인 코드를 재발송한다. 가입 시에는 서버가 자동으로 1회 발송하므로 이 엔드포인트는 재발송 용도다.

**인증** `USER`

**Request** 없음

**Response** 없음 (204)

대상 주소는 토큰의 사용자에 연결된 `LOCAL` 인증 수단의 이메일이다. 요청 바디로 주소를 받지 않는다 — 임의 주소로 메일을 보낼 수 있는 경로를 만들지 않기 위해서다.

코드는 Redis에 저장하며 유효기간 10분, 1회 사용이다 (ADR-010, `NFR-AUTH-017`). 재발송은 60초 간격, 시간당 5회로 제한한다.

| 오류 | 상황 |
| --- | --- |
| 409 `CONFLICT` | 소셜 계정이라 확인할 이메일이 없음, 또는 이미 소유 확인이 완료된 계정 |
| 429 `RATE_LIMITED` | 재발송 간격·횟수 제한 초과 |

관련: `FR-AUTH-014`, `NFR-AUTH-017`
