# 회원가입

도메인: AUTH
Method: POST
URL: /api/v1/auth/signup
Version: 1
개발완료여부: No

온보딩 완료.

**인증** — (signupToken)

**Request** `SignupRequest`

**Response** `AuthTokenResponse`

```java
// SignupRequest
{
  "signupToken": "eyJhbGci...",   // @NotBlank
  "nickname": "재현",              // @NotBlank @Size(min=2, max=20)
  "termsAgreed": true              // @AssertTrue
}

// AuthTokenResponse (201)
{
  "accessToken": "eyJhbGci...",
  "user": {
    "userId": 1,
    "nickname": "재현",
    "profileImageUrl": null
  }
}
```

| 오류 | 상황 |
| --- | --- |
| 400 `INVALID_INPUT` | 닉네임 형식 위반, 약관 미동의 |
| 401 `UNAUTHENTICATED` | signupToken 만료 |
| 409 `CONFLICT` | 닉네임 중복 |

관련: `FR-AUTH-002`
