# 카카오 로그인

도메인: AUTH
Method: POST
URL: /api/v1/auth/kakao
Version: 1
개발완료여부: No

카카오 인가 코드로 로그인 또는 가입 진입.

**인증** —

**Request** `KakaoLoginRequest`

**Response** `KakaoLoginResponse`

```java
// KakaoLoginRequest
{
  "code": "인가코드",                                  // @NotBlank
  "redirectUri": "https://reused.app/oauth/callback"  // @NotBlank
}

// KakaoLoginResponse — 기존 회원 (200)
{
  "status": "LOGIN",
  "accessToken": "eyJhbGci...",
  "signupToken": null,
  "user": {
    "userId": 1,
    "nickname": "재현",
    "profileImageUrl": "https://..."
  }
}

// KakaoLoginResponse — 신규 회원 (200)
{
  "status": "SIGNUP_REQUIRED",
  "accessToken": null,
  "signupToken": "eyJhbGci...",
  "user": null
}
```

`status`는 `LOGIN` / `SIGNUP_REQUIRED`. `user`는 `UserSummaryResponse`.

Refresh Token은 바디가 아닌 HttpOnly 쿠키로 설정한다.

`signupToken`은 카카오 회원번호를 담은 단기 토큰(10분)이다. 인가 코드는 일회용이므로 온보딩 중 만료를 방지하기 위해 별도 토큰으로 전달한다.

| 오류 | 상황 |
| --- | --- |
| 400 `INVALID_INPUT` | 인가 코드 누락·무효 |
| 403 `USER_SUSPENDED` | 이용정지 계정 |
| 502 `EXTERNAL_SERVICE_ERROR` | 카카오 API 실패 |

관련: `FR-AUTH-001`, `FR-AUTH-003`
