# 토큰 재발급

도메인: AUTH
Method: POST
URL: /api/v1/auth/refresh
Version: 1
개발완료여부: No

Access Token 재발급. Rotation 적용 (ADR-005).

**인증** — (쿠키)

**Request** 없음

**Response** `AccessTokenResponse`

```java
// AccessTokenResponse (200)
{
  "accessToken": "eyJhbGci..."
}
```

| 오류 | 상황 |
| --- | --- |
| 401 `UNAUTHENTICATED` | 쿠키 없음, 만료, 화이트리스트 미등록 |

사용된 Refresh Token이 재사용되면 해당 사용자의 전체 토큰을 무효화한다.

관련: `NFR-AUTH-002~004`
