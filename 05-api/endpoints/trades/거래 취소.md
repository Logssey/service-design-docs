# 거래 취소

도메인: TRADES
Method: POST
URL: /api/v1/trades/{tradeId}/cancel
Version: 1
개발완료여부: No

**인증** `USER` (당사자)

**Request** `TradeCloseRequest`

**Response** `TradeStatusResponse`

| 오류 | 상황 |
| --- | --- |
| 403 `FORBIDDEN` | 당사자 아님 |
| 409 `CONFLICT` | 이미 최종 상태 |

`ACCEPTED`에서 취소하면 게시글을 `ON_SALE`로 복귀시킨다.

관련: `FR-TRADE-004`, `FR-TRADE-005`
