# 거래 요청

도메인: TRADES
Method: POST
URL: /api/v1/trades
Version: 1
개발완료여부: No

**인증** `USER`

**Request** `TradeCreateRequest`

**Response** `TradeCreateResponse`

```java
// TradeCreateRequest
{
  "listingId": 101   // @NotNull
}

// TradeCreateResponse (201)
{
  "tradeId": 55,
  "status": "REQUESTED"
}
```

| 오류 | 상황 |
| --- | --- |
| 400 `INVALID_INPUT` | 본인 게시글 |
| 403 `USER_SUSPENDED` | 이용정지 |
| 409 `CONFLICT` | 게시글이 `ON_SALE` 아님, 진행 중인 요청 존재 |

관련: `FR-TRADE-001`, `FR-TRADE-003`
