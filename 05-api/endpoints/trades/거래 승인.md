# 거래 승인

도메인: TRADES
Method: POST
URL: /api/v1/trades/{tradeId}/accept
Version: 1
개발완료여부: No

**인증** `USER` (판매자)

**Request** 없음

**Response** `TradeStatusResponse`

```java
// TradeStatusResponse (200)
{
  "tradeId": 55,
  "status": "ACCEPTED",
  "changedAt": "2026-03-15T02:00:00Z"
}
```

| 오류 | 상황 |
| --- | --- |
| 403 `FORBIDDEN` | `seller_id` 불일치 |
| 403 `USER_SUSPENDED` | 이용정지 |
| 409 `CONFLICT` | `REQUESTED` 상태 아님, 이미 승인된 거래 존재, 동시 요청 충돌 |

게시글을 `RESERVED`로 전환한다. 동일 트랜잭션.

관련: `FR-TRADE-002`, `FR-TRADE-008`
