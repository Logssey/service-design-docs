# 거래 완료

도메인: TRADES
Method: POST
URL: /api/v1/trades/{tradeId}/complete
Version: 1
개발완료여부: Yes

거래 완료 확정. **구매자만 가능** (ADR-008).

**인증** `USER` (구매자)

**Request** 없음

**Response** `TradeStatusResponse`

| 오류 | 상황 |
| --- | --- |
| 403 `FORBIDDEN` | `buyer_id` 불일치. **판매자 요청도 해당** |
| 409 `CONFLICT` | `ACCEPTED` 상태 아님 |

게시글을 `COMPLETED`로 전환하고 양측에 후기 작성 알림을 발송한다.

관련: `FR-TRADE-006`, `FR-TRADE-008`
