# ADR-008 — 거래 완료 확정 주체를 구매자로 한정

**상태** Accepted

**맥락**

거래 완료를 누가 확정할지에 따라 미확정 거래의 발생 양상이 달라진다.

**결정**

- 거래 완료는 구매자만 확정할 수 있다
- 판매자는 완료를 확정할 수 없다
- 완료 확정 이후 양측 모두 후기를 작성할 수 있다
- 완료 이전에는 양측 모두 거래를 취소할 수 있다

**근거**

- 물품 수령 여부가 거래 성립의 실질적 기준이며 이를 아는 주체는 구매자다
- 판매자 단독 확정은 물품 미전달 상태에서의 임의 완료를 허용한다
- 양측 확인 방식은 한쪽이 응답하지 않을 경우 거래가 종결되지 않는다

**대안**

- 판매자 단독: 판매 이력 관리에는 편하나 구매자 보호가 약하다
- 양측 확인: 정확하나 미종결 거래가 누적된다

**결과**

- 구매자가 확정하지 않으면 거래가 승인 상태로 유지된다
- 일정 기간 경과 후 자동 완료 처리는 2차 확장에서 검토한다

**관련 요구사항** FR-TRADE-006, FR-REVIEW-001
