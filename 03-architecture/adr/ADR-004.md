# ADR-004 — 소셜 로그인 제공자를 Kakao 단독으로 한정

**상태** Accepted

**맥락**

`FR-AUTH-001`은 소셜 로그인 기반 회원가입을 요구한다. 국내 중고거래 서비스가 대상이며 제공자를 늘릴수록 연동·검증 비용이 증가한다.

**결정**

- 1차 릴리스는 Kakao만 지원한다
- 계정 식별자는 Kakao 회원번호를 사용한다
- 이메일은 선택 수집 항목으로 취급하며 계정 식별에 사용하지 않는다
- 이메일이 동일하더라도 계정을 자동 병합하지 않는다
- 관리자 계정은 별도 인증 수단을 두지 않고 기존 계정에 ADMIN 역할을 부여하는 방식으로 처리한다

**근거**

- 국내 사용자 커버리지가 높고 한국어 문서가 제공된다
- 카카오는 이메일 제공이 선택 동의 항목이므로 이메일 기반 식별은 실패할 수 있다

**대안**

- Google 병행: 커버리지는 넓어지나 연동·테스트 비용이 두 배가 된다
- 자체 계정 가입 병행: 비밀번호 저장·재설정 책임이 추가된다

**결과**

- 카카오 서비스 장애 시 로그인이 불가능하다
- 제공자 추가는 2차 확장으로 미룬다

**관련 요구사항** FR-AUTH-001~003, NFR-AUTH-005
